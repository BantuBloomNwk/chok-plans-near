    How a sealed plan works

    1

    Commit

    When a plan is made, a hash of its rules and a random salt is published. Nobody can work the rules back out of it.
    2

    Seal

    The rules live only as an OutLayer secret bound to the judge's exact code hash, opened only inside an Intel TDX enclave, only for the plan's agent, only through the plan contract.
    3

    Judge

    Each request goes to the judge. It answers cleared or refused, names the rule but never its value, and returns the hash of the rules it used.
    4

    Enforce

    The plan releases only if the hash matches the commitment, the judge cleared it, and the public cap allows it. Anything else is Busted.
