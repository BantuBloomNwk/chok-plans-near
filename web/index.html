    How a sealed plan works

    Commit

    The dev publishes a hash of their rules and a random salt when the plan is made. Anyone can see the commitment. Nobody can work the rules back out of it.

    Seal

    The rules go into OutLayer as an encrypted secret, bound to the judge's exact code hash. They're only ever decrypted inside an Intel TDX enclave.

    Judge

    Each request goes to the judge. It answers cleared or refused, names the rule that refused it but never its value, and returns the hash of the rules it used.

    Enforce

    The plan releases only if the commitment matches, the judge cleared it, and the public cap allows it. Anything else is Busted, and each Busted cuts the cap by 20%.
